I enjoy turning ideas into functional applications and continuously expanding my skills across **frontend development, backend engineering, databases, APIs, cloud deployment, and AI engineering**.

- 💻 Building full-stack applications with **React, Next.js, Node.js, Express.js, and MongoDB**
- ⚡ Creating responsive and modern interfaces using **TypeScript, Tailwind CSS, and modern UI principles**
- 🤖 Exploring **AI Agents, OpenAI Agents SDK, LangGraph, Gemini, LiteLLM, and OpenRouter**
- 🔐 Implementing secure authentication with **JWT and role-based authorization**
- 🗄️ Designing backend systems with **MongoDB, Mongoose, REST APIs, and CRUD architecture**
- 🚀 Deploying applications using modern cloud and developer platforms
- 🧠 Strengthening software engineering fundamentals through real-world projects
- 🛠️ Exploring **SaaS products, AI-powered applications, automation, and developer tools**
- 📚 Learning continuously by building, debugging, deploying, and improving
